## 方針(この実験の対照条件)

| 変えないもの | 変えるもの |
| --- | --- |
| 7ロールの並び(`logoIn` `title` `value` `program`×3 `guests` `cta` `logoOut`)、尺はナレーションが決める、字幕は本文から導出、無い事実は描かない | **色・書体・モーション・地(素材の使い方)・効果音の選曲・ナレーションの文章** |

sake-2026 の「効いた順」は前提として引き継ぐ: レターボックス > 写真主役化(方向性スクリム) > 1素材Nショット > 書体 > 常時カメラムーブ。**ただし見え方は sumi と別物にする**。sumi は「墨黒×真鍮の金×文芸の明朝×和のSFX」。こちらは「夜のホールの黒×シャンパンゴールド×古典的な明朝と欧文セリフ×弦とガラスの音」。並べたときに同じテンプレートの色替えに見えたら失敗。

### 書体

- 和文: **Zen Old Mincho**(display も text も)。sumi の Shippori Mincho より骨格が古典的で、欧文セリフと並べたときに揃う
- 欧文: **Cormorant Garamond**(300 / 400 / 500、italic)。日付・時刻・ローマ数字・キッカー(`PROGRAMME I`、`GUESTS`、`FRIDAY, OCTOBER 2, 2026`)に使う。**欧文は事実の言い換えにとどめる**(日付・曜日・時刻・ロール名)。新しいコピーを英語で作らない
- 組版: `lang="ja"` + `word-break: auto-phrase` をルート1箇所に(sake D13)。見出しはトラッキング広め(0.08〜0.14em)、キッカーは 0.4em 以上の小さな大文字

### 動き(モーション語彙)

1. **tracking-in**: 見出しが `letterSpacing 0.6em → 0.12em` へ収束しながらフェードイン。ラグジュアリーの常套だが、1シーンに1回だけ
2. **dissolve**: 地のショット間は18フレームのディゾルブ。ハードカットは章の転換(program の頭)だけ。sake は全カットをハードにしたが、こちらは緞帳の質感に合わせて溶かす
3. **chandelier bokeh**: 直径 40〜140px の大きな金の円を 12〜18 個、`filter: blur(6〜14px)`、opacity 0.06〜0.22、ゆっくり斜め上へ漂う。sake の GoldDust(小粒・多数)と同じ場所に置く別物
4. **spotlight sweep**: タイトルの上を柔らかい放射光が1回だけ横切る(`radial-gradient` を translate)。寺下氏の写真の光の帯と同じ語彙
5. **Ken Burns**: 静止画は 1.04→1.12 の push(または pan)。動画は据える(sake v7 の規則)。**クリップはループしない**
6. **hairline draw**: 金の罫線(1〜2px)が描かれる。リング(円)も同じ

### 装飾

- **レターボックス 120px**、帯色 `groundDeep`、帯の内側の縁に 1px の金線(opacity 0.35)。字幕は下帯の中(Zen Old Mincho 32px・ivory・tracking 0.08em)
- **ローマ数字の印章**: `I` `II` `III` を Cormorant 300 の 120px で、直径 220px の 1.5px の金のリングに収める。sake の「一」が裸だと棒に見える問題と同型(`I` は縦棒)——リングが視覚的質量を持ち、数字は主題のまま。sake の正方形(印章)に対して円(メダル)
- 登壇者は**全画面の分割パネル**(sake の `panels` と同じ骨格)。ただし**演奏者・製作者の3名だけ**をパネルにし、モデレーターはパネル下のクレジット行に置く(「モデレーター 加藤航介 WealthPark研究所 代表」)。理由は2つ: 加藤氏の写真は 384×216 しか無く全画面に耐えない、そしてモデレーターは演者ではないので階層が違う。写真が来たら4パネルにしてよい
- マーク(WealthPark Lab)は `transparent_dark` のSVG。暗い地では `filter: brightness(0) invert(1)` で白抜きにし、opacity 0.92 で ivory に寄せる

### 音

- BGM: `assets/audio/strung-up-joy.mp3`(3分10秒・true peak −1.5 dBFS・LRA 4.7)。曲頭から。FULL 0.62 / UNDER_VOICE 0.16 は sake の値から始めて、書き出しで測って直す
- 効果音: 共通プール `public/defaults/sfx/`(logos 側・63音・[catalog.json](../../../public/defaults/sfx/catalog.json) の実測 gain)。**和楽器は使わない**。候補: 開幕=「荘厳な雰囲気」or「きらきら輝く1」、タイトル=「キラッ1」、章転換=「ピアノの単音」or「チリン」、登壇者=「スポットライト」、締め=無音(sake と同じ理由)。sake の規則どおり `presence`(相対)だけを書き、音量は measured gain × presence。使う音だけ `public/assets/sfx/` へコピーする(gitignore)

## 所見

### v1(2026-09-10・ボイス未収録・生成素材ゼロ)

`out/v1.mp4` = 2593フレーム / 86.5秒 / 22MiB。尺はナレーション499字からの推定。静止画は `out/check/`。

- **sumi と別物に見えるかは合格。** ボルドーのベルベット・シャンパンゴールドの罫とリング・Cormorant のオールドスタイル数字(`2026.10.2`)・Zen Old Mincho が、同じ7ロールの上で別のテンプレートとして立った。CTA の日付カードと program#0(リング+寺下氏のインセット)、登壇者の3パネル+モデレーター行は、生成素材が来なくてもこのまま納品に耐える
- **地が弱いのは value と program#1。** value は名器写真の渦巻きクロップで、左端に昼光の窓(灰色の建物)が残る——夜のホールの映画に昼が1枚混ざる。program#1 は右2/3が余白でリングだけが主題。どちらも生成素材(A3/A4、B2/B3)の到着で入れ替わる前提の placeholder で、**「未完成」には見えないが「薄い」**
- **title の shot2(f字孔クロップ)は 1440px 源の1.55〜1.72倍拡大**で甘い。グレインが隠しているが、A2 で置き換える
- **実写の名器写真は昼白色・青緑のボケ**で、夜の映画の中では色温度が浮く。`saturate(0.72) brightness(0.88)` で寄せたが目測。A2 側に「遠景の青緑のボケ1点」を入れて繋ぐ(ASSET-PROMPTS.md)
- **効果音は測定で確認済み**(BGM の包絡を差し引いた残差が全キューで −24〜−28 dB RMS、床は −54 dB)。ピアノの単音は音楽より9dB下で、ボイスが入って BGM が 0.16 に落ちるまでは聞こえない。**声が入ってから聴いて決める**
- **描画層で直したもの**: インセットが自分のキャプションを塗っていた(`Photo` が AbsoluteFill で親が未配置)/ モデレーター行が土屋氏のキャプションに読めた(見出し帯と脚注帯を分けた)/ プログラム名の孤立改行(`textWrap: balance` + maxWidth)
- **FINDINGS からの逸脱**: program#1 のリングは 300px(他は 220px。インセットが無いので主題として大きくした)/ `valueLines[2]` は描かない(cta 本文と同文)/ `FRI` は金(キッカー扱い)
- **持ち帰り候補(仮説)**: ローマ数字のリング(`stat` の variant `ring`)/ ベルベットの placeholder ground(`ThemeBackdrop` に素材ゼロの地の第2種)/ ショット間ディゾルブ(`ThemeMotion.transition` に `dissolve`)/ 登壇者の「パネル+クレジット行」(演者と進行役の階層)/ 欧文の日付カード(`schedule` の描き方をテーマが持つ)

### v2〜v4(2026-09-10〜11・ボイス収録・生成静止画13枚・生成クリップ8本)

`out/v4.mp4` = 119.7秒。静止画は `out/check3/`(v2)`check4/`(v3)`check6/`(v4)。

- **TTS の速度は指示で制御できない。** 1回目のペルソナ(「ゆったり」「一語一語を置くように」)は 499字を 120.8秒(4.1字/秒)で読み、sake の実測 5.2〜6.5字/秒 より3割遅かった。速度の語を全部外して録り直しても 111.7秒(4.5字/秒)——**8%しか動かない**。尺を詰める手段は台本を削ることだけ。`record-narration.mts` の `luxe` ペルソナに実測を残した
- **16:9 の素材に `focus` は効かない。** 1456×816(1.784:1)を 1920×1080(1.778:1)に cover すると横の余りは全体で 7px。`object-position` の可動域は ±3.5px で、配役の「被写体を左に寄せる」は全部 **Ken Burns の x/y ドリフト**に翻訳した。端が入らない上限は `|x| ≤ 50.19 − 50/s`、`|y| ≤ 50(s−1)/s`(sources.ts 冒頭)。sake の写真は縦横比が様々だったので focus で足りていた——**16:9 で作る生成素材では、寄せは scale と drift でやる**
- **クリップは終端まで見てから尺を決める。** b2(3挺の rotate-in)は終端で3挺が画面いっぱいになり、渦巻きの先端が上の帯(クリップ比率 y<0.1172、cover の縦切れ8.6pxを含む)に隠れる。0.1秒刻みで先端を実測し **3.0秒が無傷の最後**、スロットは 2.90秒。「クリップは1回だけ、切れる前にカット」(sake v8)に「**帯に隠れる前にカット**」が加わった
- **クリップの尺の余裕は 0.35秒以上。** 5.18秒の素材に 4.8秒のスロット。ディゾルブ(18f)の重なりぶんを含めて、丸めでフリーズしない
- **BGM の頭は曲そのものが無音だった。** フレーム0から FULL にしても 1.8秒鳴らない(実測: 1.7秒まで −84dB、1.8秒で −20.8dB)。`trimBefore={54}` で曲頭を切った。**「頭から鳴らす」はエンベロープでは保証できず、素材の測定が要る**(sake の SFX と同型)
- **登壇者3パネルの明るさは実測で揃える。** 土屋氏の白ホリだけ平均輝度 124.9 で、寺下氏 67.6・カポラリ氏 82.8 と並ぶと別の映画。そのパネルだけ `brightness(0.52) sepia(0.14)` で **84.8** に。顔ボックスは 97.7(寺下氏 93.8 と同水準)で沈んでいない。`saturate` は 0.95 に**上げて**赤いアコーディオンを残した
- **文字の下の輝度を測って寄せる向きを決める。** program#1 の f字孔クロップを指示どおり右へ寄せると文字の下が輝度 42(p90 95)で「文字が楽器に乗る」が再発。予算内の (scale, drift) を総当たりで評価して左へ寄せ、13(p90 30)に。**配役の指示は「どこに寄せるか」ではなく「文字の下を暗くせよ」で出すべき**だった
- **効果音**: 依頼者指示で冒頭2つ(きらきら輝く1・キラッ1)を外し、残りはプログラムのピアノ単音×3と登壇者のスポットライト。冒頭は依頼者の指定待ち
- **残っている問題**: ① program#1 の3ショット目(b2 の f字孔寄り、1.82倍)と program#2 の2ショット目(b4 寄り、1.87倍)が甘い。映像素材で置き換えるのが本筋 ② タイトル1ショット目は a2 クリップで暫定。本命は A0(KV)の生成待ち ③ CTA の締めに後ろ姿の人物(d1 クリップ)を使ってよいかは依頼者判断 ④ 尺 119.7秒の可否は依頼者判断

### シーンごとのディレクション(2026-09-11・依頼者レビュー第1巡)

依頼者が v5 を見て、シーン単位で指示を出した。**この巡で決まったことは、テンプレートの契約に返るものが多い。**

- **同じ素材を動画と静止画の両方に使うと、同じシーンが2回出たように見える。** 5シーンで起きていた(a3 / b1 / b2 の「クリップ→同じ画像の静止画」、b4 / e5 の「同じ静止画の2クロップ」)。sake の「1素材Nショット」は写真同士では効いたが、**クリップの直後に同じ画像の静止画を置くのは不可**(動いていたものが止まって見える)。埋めるための新スロット A5 / B5 / B6 / B7 と既出の C1 を ASSET-PROMPTS.md に追加
- **画面の文字はナレーションの写しではない。** テーマのシーンでは、ナレーション106字がそのまま画面に出ていて「視覚情報が多すぎる」。声が文章を言い、画面は**短い一行**(「人生で一度は、目の前で。」+ 事実の一行)。CTA も同様に、話す言葉と見せる言葉を分けた。**テンプレートでは `valueLines` を画面用の短文、`narration` を話す文として、別のフィールドとして扱うべき**——いまは seed が同じ文を両方に入れる
- **プログラムの出演者は全員を画面に出す。** program#0 に土屋氏を足した(寺下氏が主役で左、同サイズで右)。出演者が2名いるのに1名だけ見せると「問題になる」(依頼者)。テンプレートの `programs[].guests` のような結び付けが要る(いまはシーン固有の対応表)
